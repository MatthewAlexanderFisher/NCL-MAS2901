2  What is Statistical Inference?

NoteLearning objectives
  • Distinguish a target population, the random variables in a sample, and their observed data values.
  • State the goal of statistical inference: using observed data to learn about a population distribution.
  • Explain the iid assumption and why it is not the same as representative sampling.
  • Read a provided statistical model and identify its parameter(s) \theta and parameter space \Theta.
  • Connect common univariate data types to plausible probability models, while recognising that models are approximations.

Constructing a model from scratch and the fully formal definition of a model are useful context, but are explicitly marked non-examinable later in the chapter.

bodyFont = getComputedStyle(document.body).fontFamily

Statistical inference underpins experimental science, machine learning, clinical trials, and more. This chapter first separates population, sample, and observed data; then classifies common data; and finally shows how a statistical model connects data to an unknown parameter. The overall aim is:

  • Given observed data from a sample connected to a clearly defined target population,
  • Draw a justified conclusion about the population’s distribution.

Typical conclusions include estimating a proportion or mean, quantifying uncertainty, comparing groups, or predicting future outcomes.

NoteRecurring example: study-space preferences

Suppose the target population is all students eligible to use two campus study spaces this term. For student i, let X_i=1 if they prefer space A and X_i=0 if they prefer space B. The population proportion p who prefer A will provide a simple thread through this chapter and the next.

Important 2.1: Notation: \mathrm{Distribution}(\theta)

In the following, we use \mathrm{Distribution}(\theta) as a placeholder to mean:

“a distribution depending on parameter \theta.”

For example:

  • \mathrm{Distribution}(\mu,\sigma^2) = \mathcal{N}(\mu,\sigma^2)
  • \mathrm{Distribution}(p) = \mathrm{Bernoulli}(p)

This allows us to keep the definitions general!

Important 2.2: Terminology: Population, Sample, Data
  • Target population: the broader group or collection of outcomes to which we want our conclusion to apply. It may be concrete, such as current students, or conceptual, such as future comparable patients.
  • Population distribution: the probability distribution describing a randomly selected outcome from that target population under our assumptions.
  • Sample (before observation): the random variables X_1,X_2,\ldots,X_n used to represent the measurements we will observe.
  • Observed sample / data: the realised values x_1,x_2,\ldots,x_n after measurement.
  • Observation / data point: one measurement, represented by X_i before observation and x_i afterwards.

Note: In everyday usage, sample often means the observed dataset itself. In mathematical derivations we distinguish the random sample \underline{X}=(X_1,\ldots,X_n) from its realised value \underline{x}=(x_1,\ldots,x_n).

2.1 Statistical Inference as “Inverse Probability”

In probability theory, the usual direction is:

  • Start with a distribution f(x \mid \theta) for one outcome (the model, with known parameter \theta).
  • Use it to generate random samples, or calculate probabilities of events involving the data.

In statistical inference, we reverse the problem:

  • We observe data \underline{x} = (x_1,\ldots,x_n).
  • The distribution f(x \mid \theta) is only partially known, through the unknown parameter \theta.
  • Our task is to use the observed data to learn about \theta, and hence about the population distribution.

Formally, we (usually) assume our data are an i.i.d. sample:

X_1,\ldots,X_n \stackrel{\text{iid}}{\sim} \mathrm{Distribution}(\theta).

  • Independent: observing one X_i does not change the distribution of any other.
  • Identically distributed: each X_i comes from the same population distribution f(x \mid \theta).

The goal of statistical inference is to use the observed sample to learn about \theta, and hence about the underlying population.

Important 2.3: Terminology: Random Sample

  • A sample 2.2 means the n random variables used to represent our measurements before observation, X_1,\dots,X_n. These need not be independent or identically distributed.

  • A random sample is the special case where the X_i are assumed independent and identically distributed (i.i.d.) from the same distribution: X_1, \dots, X_n \stackrel{\text{iid}}{\sim} \mathrm{Distribution}(\theta).

Most of the inference procedures in this course are developed under the random-sample (iid) assumption.

The mathematical term random sample does not by itself guarantee that the observed people or objects represent the target population. Selection bias, under-coverage, or non-response can make an iid model inappropriate for the target of interest. Conversely, a simple random sample drawn without replacement from a finite population is not exactly independent, although the iid approximation is often reasonable when the population is much larger than the sample.

2.2 Types of Data

Before we build statistical models, it helps to think about the kinds of data we might collect. Different data types naturally lead to different models.

WarningScope of this course

The assessed methods in this course focus on univariate data: one measurement per observational unit. Multivariate and high-dimensional examples below provide context for later courses and may be skimmed on a first reading.

2.2.1 Univariate vs. Multivariate data

Important 2.4: Terminology: Unit

An observational unit (or simply unit) is a single element of the population on which we make a measurement.

  • In a survey of students: each student is a unit.
  • In a clinical trial: each patient is a unit.
  • In a manufacturing study: each product is a unit.
  • In an image analysis study: each image is a unit.

  • Univariate data: a single measurement per observational unit.

    Example: the height of each student in a class.

  • Multivariate data: two or more measurements on each unit.

    Example: the height and weight of each student (bivariate); or height, weight, and age (multivariate).

Data are often represented in tables.

  • Univariate data
  • Multivariate data

Each unit has one measurement.

Here, the units are the years (2011–2020), and the (single) variable is the annual count of UK earthquakes.

Each unit has two or more measurements.

Here, the units are the weather stations (during the same storm), and the variables are rainfall (mm), wind speed (km/h), and pressure (hPa).

Some data are extremely high-dimensional. The following example is enrichment rather than assessed content.

NoteEnrichment: image data

Example 2.1 (Image Data) An image is made of a grid of pixels, where each pixel is a colour.

A colour can be represented by three channels: red, green, and blue1.

If the whole image is one observational unit, each pixel–channel position is one variable. An image is therefore a high-dimensional multivariate observation. To see why, consider the size of real images:

  • A tiny image of size 32\times 32 pixels with 3 channels (RGB) already has 32\times 32 \times 3 = 3072 measurements.
  • A small image of size 128 \times 128 pixels with 3 channels (RGB) has
    128 \times 128 \times 3 \approx 50{,}000 measurements.
  • A “HD” photo of size 1920 \times 1080 (1080p) contains over
    1920 \times 1080 \times 3 \approx 6.2 million measurements.

So even a single image can be thought of as a very high-dimensional observation. And videos are higher still: sequences of such images evolving over time2.

2.2.2 Numerical data

  • Continuous: can take any real value in an interval.

    Examples: height, weight, reaction time.

    Models: Normal, Exponential, Uniform.

  • Discrete numeric: counts, usually non-negative integers.

    Examples: number of accidents in a week, number of goals in a football match.

    Models: Binomial, Poisson, Geometric.

  • Continuous data
  • Discrete data
  • Mixed data

In practice, most datasets are mixed.

2.2.3 Categorical data

  • Nominal: categories with no natural order.

    Examples: hair colour, brand of cereal, country of birth.

  • Ordinal: categories with a natural order, but not numerical spacing.

    Examples: customer satisfaction ratings (“poor”, “fair”, “good”, “excellent”).

Categorical data are often summarised in contingency tables (tables of counts).

  • One-way table
  • Two-way table

If we record the colours of sweets drawn from a bag:

2.3 Statistical Models

Whenever we perform statistical inference, we must specify a model.

A model records assumptions about both the distribution of each observation and how observations relate to one another. Choosing a named distribution is therefore only one part of modelling; assumptions such as independence and a common parameter matter too.

In Section 2.1 we wrote X_1,\ldots,X_n \stackrel{\text{iid}}{\sim} \mathrm{Distribution}(\theta) using \mathrm{Distribution}(\theta) as a placeholder for “some distribution indexed by \theta”.

We now make this precise:

A statistical model is a mathematical description of how we think the data are generated.
Concretely, it is a family of possible distributions, one for each parameter value in a parameter space \Theta.

Example 2.2 (Exponential model) Suppose we are interested in modelling waiting times until some event occurs (e.g. the time between customer arrivals at a service desk).

A natural assumption is that the data are i.i.d. exponential 3.2: X_1,\ldots, X_n \stackrel{\text{iid}}{\sim}\mathrm{Exponential}(\lambda).

  • Model: each X_i is i.i.d. exponential with rate \lambda
  • Parameter: \theta = \lambda
  • Parameter space3 : \Theta = \{ \lambda \mid \lambda > 0\} = (0,\infty)

The exponential model often arises in Poisson processes, where events occur independently at a constant rate (e.g. radioactive decay or customer arrivals at a service desk).

Example 2.3 (Normal model) In Section 2.1.1 we assumed the data were i.i.d. Normal with unknown mean and variance: X_1,\ldots, X_n \stackrel{\text{iid}}{\sim} \mathcal{N}(\mu, \sigma^2).

  • Model: each X_i is i.i.d. Normal with mean \mu and variance \sigma^2
  • Parameters: \theta = (\mu,\sigma^2)
  • Parameter space4 : \Theta = \{ (\mu, \sigma^2) \mid \mu \in \mathbb{R}, \sigma^2 > 0 \} = \mathbb{R} \times (0,\infty)

This model is widely used, e.g. for measurement error or traits like human height.

TipCheckpoint: question the model

A useful model need not be literally true, but its assumptions should be reasonable for the intended purpose.

  1. Why might an exponential model be poor for waiting times when the arrival rate changes sharply during the day?
  2. What feature of a Normal model makes it only an approximation for human height?
Check your answer
  1. A single exponential rate assumes a constant event rate (and the associated memoryless waiting-time structure); a changing rate violates that assumption.
  2. A Normal distribution is symmetric and has unbounded support, so it assigns some probability to impossible negative heights. It can nevertheless approximate the central part of a height distribution well.
TipCommon Misconceptions

  • Parameter \neq statistic.
    A parameter \theta describes a feature of the population (e.g. p, \mu, \sigma^2).
    A statistic (e.g. \bar{X}, a sample proportion) is calculated from the sample and used to learn about \theta.

  • “Random sample” is not just “whatever data we found”.
    In this course, a random sample is the mathematical iid model for X_1,\ldots,X_n. Whether that model supports inference to the target population also depends on the recruitment or sampling mechanism.

    Example: If the target population is all humans on the planet, observations from one family may be dependent and will not represent the full target population.

  • Models are approximations.
    In practice you should treat models as useful simplifications, not as exact descriptions of reality. It’s important to choose them sensibly, and be prepared to adjust if they don’t fit the data well.

Example 2.4 (From words to a model) Return to the study-space survey. A response is recorded as 1 for preference A and 0 for preference B. Write down a simple model and identify the parameter.

Solution

Let X_i=1 if respondent i prefers A, and 0 otherwise.

Assume X_1,\ldots,X_n \stackrel{\text{iid}}{\sim}\mathrm{Bernoulli}(p).

  • Model: \mathcal{P} = \{ \mathrm{Bernoulli}(p) : 0 \leq p \leq 1 \}
  • Parameter: \theta = p
  • Parameter space: \Theta = [0,1]

Here p is the probability that a randomly selected member of the target population prefers A. The common-p and independence assumptions would be questionable if recruitment favoured one type of student or responses influenced one another.

Example 2.5 (A slightly richer example) A bag contains sweets of three colours \{\text{red},\text{blue},\text{green}\}. You draw n sweets with replacement and record counts (R,B,G). Propose a model and identify the parameters.

Solution

Each draw is an independent categorical outcome with probabilities (p_R,p_B,p_G) for red/blue/green. After n draws, we observe the count vector (R,B,G).

A natural model is the multinomial 2.3 distribution:

  • Model: (R,B,G) \sim \mathrm{Multinomial}\!\left(n;\,p_R,p_B,p_G\right) with p_R+p_B+p_G=1
    (equivalently, X_1,\dots,X_n \stackrel{\text{iid}}{\sim} \mathrm{Categorical}(p_R,p_B,p_G) and (R,B,G) are the totals).
  • Parameters: \theta = (p_R,p_B,p_G)
  • Parameter space: the 2-simplex \;\Theta=\{(p_R,p_B,p_G)\in[0,1]^3 \mid \,p_R+p_B+p_G=1\}

Although three probabilities are written down, only two are free: the third is determined by the constraint that they sum to one.

If you only had two colours, the multinomial distribution would become the binomial distribution 2.2.

NoteEnrichment: a conditional model in machine learning

Example 2.6 (Machine learning example) In image classification, each “training” example is a pair (X_i,Y_i) where X_i is an image and Y_i\in\{0,1\}. A generic probabilistic model specifies \mathrm{Pr}_\theta(Y=1\mid X=x)=g_\theta(x), for some family of functions g_\theta (e.g. a neural network).

What are the sample, population, model, and parameter?

Solution
  • Sample: the dataset \{(X_i,Y_i)\}_{i=1}^n.
  • Target population: the conceptual collection of image–label pairs to which we want the classifier to generalise. Its real-world distribution determines how frequently different pairs occur.
  • Model: we specify the conditional distribution of Y given X, Y \mid X \sim \mathrm{Bernoulli}\big(g_\theta(X)\big), i.e. \mathrm{Pr}_\theta(Y=1\mid X=x)=g_\theta(x).
  • Parameter: \theta indexes the function g_\theta (e.g. regression coefficients or neural-network weights).
  • Parameter space: \Theta\subseteq\mathbb{R}^d (dimension d depends on the chosen model class).

This is a conditional model: it specifies Y\mid X while treating the input images as given. It does not by itself specify a marginal distribution for X or a full joint model for (X,Y).

Common misconception: confusing the training sample (finite) with the population (conceptual/infinite). The goal of inference is to use the sample to learn \theta so that the model generalises to the population.

Warning 2.1: Non-Examinable Content: Specifying Statistical Models

In this course we concentrate on how to carry out statistical inference once a model has been chosen.

In all assessed questions the statistical model will be provided. Your task will be to perform inference by working with the parameter(s), using methods such as:

  • Parameter Estimation 4
  • Interval Estimation 7
  • Hypothesis Testing 9

The (non-examinable) formal definition of a statistical model is the following:

Definition 2.1 (Statistical Model (non-examinable)) A statistical model5 is a family of probability distributions labelled by a parameter value: \mathcal{P}=\{P_\theta \mid \theta\in\Theta\},

where:

  • P_\theta is one possible distribution the data might follow,

  • \theta is the parameter,

  • \Theta is the parameter space (the set of all possible parameter values).

2.4 Chapter summary

  • A target population states where we want to generalise; the random sample \underline{X} represents uncertain measurements and \underline{x} denotes the values actually observed.
  • An iid model assumes independence and a common distribution, but representativeness also depends on how observations enter the sample.
  • A statistical model links possible data distributions to parameter values in \Theta. The parameter describes the population; a statistic is computed from a sample.
  • Data type and scientific context guide model choice, while model criticism asks which assumptions are useful approximations and which may be damaging.

  2. Note on compression. In practice, images are often compressed (e.g. JPEG, PNG), which reduces file size by exploiting redundancy in pixel values. Statistically, though, the raw number of pixel measurements still reflects the dimensionality of the data.↩︎

  3. Set notation. There are several equivalent ways to write sets:

    • Set-builder notation: \{\lambda \mid \lambda > 0\}
    • Interval notation: (0,\infty)
    • Named set: \mathbb{R}^+

    All three describe the same set. In this course, we recommend using set-builder notation when writing statistical models and their parameter spaces.↩︎

  4. Set notation (multiple parameters). When a model has several parameters, it is best to use set-builder notation and collect the parameters into a vector \underline{\theta} = (\theta_1, \theta_2, \ldots, \theta_p). The parameter space can then be written as \Theta = \{(\theta_1,\ldots,\theta_p) \mid \theta_1 \in S_1,\ \ldots,\ \theta_p \in S_p\}.

    Here each S_j is the set of allowed values for parameter \theta_j. To construct \Theta, simply read off the constraints on each parameter from the definition of the distribution (see the Formula Sheet 1).

    For example, in the Normal model:

    • \mu \in \mathbb{R} (any real number),
    • \sigma^2 \in (0,\infty) (variance must be positive),

    so the parameter space is

    \Theta = \mathbb{R} \times (0,\infty).

    This is called a Cartesian product: we form the parameter space by taking all possible pairs (\mu, \sigma^2) where the first component is from \mathbb{R} and the second from (0,\infty).
    Intuitively, it’s just “all combinations” of the allowed values for each parameter.↩︎

  5. Note on Statistical models. Strictly speaking, the model refers to the joint distribution of the full dataset. If X_1,\dots,X_n are i.i.d. from P_\theta, then the model is \mathcal{P} = \{ P_\theta^n \mid \theta \in \Theta \}. But for intuition, we usually just describe the distribution of a single observation, X_i \sim P_\theta, and keep in mind that the whole dataset follows from this.↩︎
