NoteLearning objectives

By the end of this chapter, you should be able to:

  • interpret posterior probability statements about a parameter;
  • distinguish a credible interval from a confidence interval;
  • explain why many credible sets can contain the same posterior probability; and
  • construct and interpret a highest-density region in simple cases.

8.1 The Bayesian perspective

Recall from Chapter 6 that Bayesian inference returns a full distribution over the parameter - the posterior 6.2: \pi(\theta \mid \underline{x}) \ \propto\ \pi(\theta)\, f(\underline{x}\mid\theta).

From this posterior we can construct a Bayesian credible interval, which represents a range of parameter values that are plausible given the data, the sampling model and the prior assumptions.

Definition 8.1 (Credible interval) A 100(1-\alpha)\% credible set for \theta is a set C_\alpha such that \Pr(\theta \in C_\alpha \mid \underline{x}) \;=\;\int_{C_\alpha}\!\pi(\theta\mid \underline{x})\,\mathrm{d}\theta \;=\;1-\alpha . When C_\alpha is connected, we call it a credible interval. For discrete \theta, replace the integral by a sum; exact equality may be impossible, in which case a set with posterior probability at least 1-\alpha is commonly reported.

For a continuous posterior distribution, there are generally infinitely many valid (1-\alpha) credible sets, and often many credible intervals.

function betaPDF(x, alpha, beta) {
  if (x <= 0 || x >= 1) return 0;
  // Using the log-gamma function for numerical stability
  const logBeta = lgamma(alpha) + lgamma(beta) - lgamma(alpha + beta);
  return Math.exp((alpha - 1) * Math.log(x) + (beta - 1) * Math.log(1 - x) - logBeta);
}

function lgamma(z) {
  const g = 7;
  const p = [0.99999999999980993, 676.5203681218851, -1259.1392167224028,
             771.32342877765313, -176.61502916214059, 12.507343278686905,
             -0.13857109526572012, 9.9843695780195716e-6, 1.5056327351493116e-7];
  
  if (z < 0.5) return Math.log(Math.PI) - Math.log(Math.sin(Math.PI * z)) - lgamma(1 - z);
  
  z -= 1;
  let x = p[0];
  for (let i = 1; i < g + 2; i++) x += p[i] / (z + i);
  
  const t = z + g + 0.5;
  return Math.log(2 * Math.PI) / 2 + (z + 0.5) * Math.log(t) - t + Math.log(x);
}

// Beta CDF using incomplete beta function (numerical approximation)
function betaCDF(x, alpha, beta) {
  if (x <= 0) return 0;
  if (x >= 1) return 1;
  
  // Use regularized incomplete beta function
  // For simplicity, using numerical integration
  const n = 1000;
  const h = x / n;
  let sum = 0;
  
  for (let i = 1; i < n; i++) {
    const t = i * h;
    sum += betaPDF(t, alpha, beta);
  }
  
  return h * (betaPDF(0, alpha, beta) / 2 + sum + betaPDF(x, alpha, beta) / 2);
}

// Inverse CDF using bisection method
function betaInvCDF(p, alpha, beta) {
  if (p <= 0) return 0;
  if (p >= 1) return 1;
  
  let low = 0, high = 1;
  const tol = 1e-6;
  
  while (high - low > tol) {
    const mid = (low + high) / 2;
    const cdf = betaCDF(mid, alpha, beta);
    
    if (cdf < p) {
      low = mid;
    } else {
      high = mid;
    }
  }
  
  return (low + high) / 2;
}
// Generate intervals based on number of segments
function generateIntervals(nIntervals, targetProb, alpha, beta) {
  const intervals = [];
  const remainingProb = 1 - targetProb; // This is α
  
  if (nIntervals === 1) {
    // Single interval: use equal-tailed interval as default
    const tailProb = remainingProb / 2;
    intervals.push({
      start: betaInvCDF(tailProb, alpha, beta),
      end: betaInvCDF(1 - tailProb, alpha, beta),
      prob: targetProb
    });
  } else {
    // Multiple intervals: distribute probability evenly
    const probPerInterval = targetProb / nIntervals;
    const gapProb = remainingProb / (nIntervals + 1);
    
    let cumProb = gapProb;
    for (let i = 0; i < nIntervals; i++) {
      const start = betaInvCDF(cumProb, alpha, beta);
      cumProb += probPerInterval;
      const end = betaInvCDF(cumProb, alpha, beta);
      cumProb += gapProb;
      
      intervals.push({ start, end, prob: probPerInterval });
    }
  }
  
  return intervals;
}

Observe and explain. The posterior probability alone does not choose a unique set. This motivates additional conventions such as equal-tailed intervals and highest-density regions.

This mirrors the frequentist setting, where many procedures can have the same nominal coverage, though in practice one often chooses a canonical version (for example, the symmetric interval around the estimator).

8.2 Interpreting Credible Intervals

A 95\% credible interval means that, given the observed data and the prior, there is a 95\% posterior probability that \theta lies inside the chosen interval. The probability statement is about the parameter itself, conditional on the data at hand.

In contrast, a 95\% confidence interval is a procedure: if we were to repeatedly draw new samples and reconstruct a confidence interval each time, then 95\% of those intervals would cover the true parameter. It does not mean there is a 95\% chance that \theta lies inside the one interval we have.

Thus, credible intervals are often more natural to interpret, but they depend explicitly on the prior, sampling model and data. They do not automatically have 95\% repeated-sampling coverage.

TipCheckpoint: confidence or credible?

Decide whether each statement describes a 95\% confidence interval or a 95\% credible interval:

  1. “Conditional on this model, prior and dataset, the posterior probability that \theta lies in the interval is 0.95.”
  2. “Across repeated samples, the construction method covers the fixed \theta on 95\% of occasions.”

The first is Bayesian; the second is frequentist. Numerically identical endpoints do not make the interpretations identical.

8.3 Highest Density Intervals

Definition 8.2 (Highest Density Region (HDR)) A 100(1-\alpha)\% highest density region (HDR) for \theta is the region

C_\alpha = \{\theta :~ \pi(\theta \mid \underline{x}) \geq \gamma \},

where \gamma is chosen so that \mathrm{Pr}(\theta \in C_\alpha \mid \underline{x}) = 1-\alpha.

Under standard regularity conditions, an HDR has the smallest total length among regions containing posterior probability 1-\alpha. For a continuous unimodal posterior it is usually one interval, often called a highest density interval (HDI).

// Find intersection points where betaPDF(x) = gamma using bisection
function findHDIBounds(gamma, alpha, beta, tol = 1e-6) {
  // First, find the mode of the distribution
  const mode = (alpha > 1 && beta > 1) 
    ? (alpha - 1) / (alpha + beta - 2) 
    : (alpha >= beta ? 0.99 : 0.01);
  
  const maxPDF = betaPDF(mode, alpha, beta);
  
  // If gamma is above the max, no valid HDI
  if (gamma >= maxPDF) {
    return { lower: mode, upper: mode, valid: false };
  }
  
  // If gamma is very small, return full interval
  if (gamma <= 1e-10) {
    return { lower: 0, upper: 1, valid: true };
  }
  
  // Find lower bound: search in [0, mode]
  let lo = 0, hi = mode;
  while (hi - lo > tol) {
    const mid = (lo + hi) / 2;
    if (betaPDF(mid, alpha, beta) < gamma) {
      lo = mid;
    } else {
      hi = mid;
    }
  }
  const lower = (lo + hi) / 2;
  
  // Find upper bound: search in [mode, 1]
  lo = mode;
  hi = 1;
  while (hi - lo > tol) {
    const mid = (lo + hi) / 2;
    if (betaPDF(mid, alpha, beta) > gamma) {
      lo = mid;
    } else {
      hi = mid;
    }
  }
  const upper = (lo + hi) / 2;
  
  return { lower, upper, valid: true };
}

Observe and explain. The region retains parameter values whose posterior density exceeds the threshold. For a requested credibility, \gamma is chosen so that the included posterior mass is 1-\alpha.

If the posterior distribution has several separated modes, then an HDR may be the union of several disjoint intervals. For example,

C_\alpha = (a,b)\cup(c,d)\cup(e,f), \quad a<b<c<d<e<f.

Example 8.1 (Beta HDI) Suppose that the posterior distribution for \theta is a \mathrm{Beta}(1,24) distribution, with probability density function

\pi(\theta \mid \underline{x}) = 24(1-\theta)^{23}, \quad 0<\theta<1.

Determine the 100(1-\alpha)\% HDI for \theta.

Solution

The HDR must include those values of \theta with highest posterior density and so, up to endpoints of posterior probability zero, takes the form C_\alpha=[0,b]. The endpoint b must satisfy

\int_0^b 24(1-\theta)^{23}\,d\theta = 1-\alpha.

Now,

\int_0^b 24(1-\theta)^{23}\,d\theta = \left[-(1-\theta)^{24}\right]^b_0 = 1-(1-b)^{24}.

Hence,

1-(1-b)^{24} = 1-\alpha \quad\Longrightarrow\quad 1-b=\alpha^{1/24} \quad\Longrightarrow\quad b=1-\alpha^{1/24}.

Therefore, a 100(1-\alpha)\% HDI for \theta is

[0,\, 1-\alpha^{1/24}].

For example, the 95\% HDI is approximately [0,0.117]. Conditional on the model, prior and data that produced this posterior, there is 0.95 posterior probability that \theta lies in this interval.

Example 8.2 (Normal HDI) Suppose we have a random sample \underline{x} from a \mathcal{N}(\mu,1/\tau) distribution (where \tau is known).

Suppose the posterior distribution is

\mu \mid \underline{x} \sim \mathcal{N}\!\left(\bar x,\; \tfrac{1}{n\tau}\right).

Determine the 100(1-\alpha)\% HDI for \mu.

Solution

This distribution has a symmetric bell shape and so the HDI takes the form C_\alpha=(a,b) with end-points

a=\bar x - \frac{z_{1-\alpha/2}}{\sqrt{n\tau}}, \qquad b=\bar x + \frac{z_{1-\alpha/2}}{\sqrt{n\tau}},

where z_p=\Phi^{-1}(p) is the lower-tail p-quantile of the \mathcal{N}(0,1) distribution.

Therefore, the 95\% HDI for \mu is

\left(\bar x - \frac{1.96}{\sqrt{n\tau}},\; \bar x + \frac{1.96}{\sqrt{n\tau}}\right).

Note that this interval is numerically identical to the 95% frequentist confidence interval for the (population) mean of a normal random sample with known variance.

However, the interpretation is very different.

Example 8.3 (Revisiting the Skeleton-Length Example) In Example 7.1, n=30, \bar{x}=161.72 cm and the sampling variance was assumed known to be \sigma^2=100 cm^2. Suppose a Bayesian analysis instead uses the prior \mu\sim\mathcal N(160,25). Find the posterior distribution and a 95\% credible interval.

Solution

Because \bar X\mid\mu\sim\mathcal N(\mu,100/30), Normal–Normal conjugacy gives V_{\mathrm{post}} =\left(\frac{1}{25}+\frac{30}{100}\right)^{-1} =2.941, and m_{\mathrm{post}} =V_{\mathrm{post}} \left(\frac{160}{25}+\frac{30(161.72)}{100}\right) =161.518. Hence \mu\mid\underline{x}\sim\mathcal N(161.518,2.941), and the 95\% equal-tailed interval (also the HDI here) is 161.518\pm1.96\sqrt{2.941} =\boxed{[158.16,164.88]}\ \text{cm}.

Given the Normal model, this prior and the observed data, the posterior probability that \mu lies in this interval is 0.95. The frequentist interval in Example 7.1 is numerically similar, but it describes the repeated-sampling coverage of a procedure. The Bayesian interval is slightly pulled towards the prior mean 160 cm.

8.4 Chapter summary

  • Credible intervals make posterior probability statements conditional on a model, prior, and observed data.
  • A credibility level does not uniquely determine a set, so conventions such as equal-tailed intervals and highest-density regions are used.
  • Highest-density regions collect the most locally probable parameter values and need not be connected in more complicated posteriors.
  • Confidence and credible intervals can sometimes share endpoints, but they answer different probability questions.
